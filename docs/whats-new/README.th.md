## <a id="v1.30.7"></a>เพื่อนตัวน้อยไม่โผล่มาบังวิดีโออีกแล้ว

<sub>1.30.7 · 10 ตุลาคม 2569</sub>

เมื่อเพื่อนตัวน้อยหรือลูกบอลอยู่หลังหน้าต่าง ก็จะอยู่ตรงนั้นต่อแม้ตอนกระโดดหรือบิน

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/pet-dark.png"><img src="../media/pet-light.png" width="340" alt=""></picture>

ก่อนหน้านี้ ถ้าเพื่อนตัวน้อยหรือลูกบอลหลบอยู่หลังวิดีโอหรือเกม การกระโดดหรือบินอาจพาพวกมันโผล่ขึ้นมาบนสิ่งที่คุณกำลังดู และการกดสเปซบาร์เพื่อหยุดวิดีโอก็ทำให้เพื่อนตัวน้อยออกมาด้วย

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/whats-new/1.29.0/pet-ball-dark.png"><img src="../media/whats-new/1.29.0/pet-ball-light.png" width="340" alt=""></picture>

ตอนนี้ ไม่ว่าจะทำอะไร พวกมันจะอยู่หลังหน้าต่างที่บังอยู่ และวิดีโอเต็มจอใน Firefox จะซ่อนพวกมันทันที

ส่วนหลังหน้าต่างทั่วไป พวกมันก็ยังหลบอยู่เหมือนเดิม

**ลองใช้:** เปิดวิดีโอในหน้าต่างใหญ่ที่บังด้านล่างของจอ แล้วกดสเปซบาร์เพื่อหยุดชั่วคราว เพื่อนตัวน้อยจะอยู่หลังวิดีโอต่อไป

**ลองใช้:** ขยายหน้าต่างให้เต็มจอ เริ่มลากกรอบเลือกบนเดสก์ท็อปข้าง Dock เพื่อให้เพื่อนตัวน้อยปีนขึ้นไป แล้วค่อย ๆ ลากขึ้นด้านบน เพื่อนตัวน้อยจะนั่งกรอบเลือกขึ้นไปอยู่ด้านหน้าของหน้าต่าง

## <a id="v1.30.0"></a>«ออก» ไม่ปิด pikapik อีกต่อไป

<sub>1.30.0 · 9 ตุลาคม 2569</sub>

เผลอกด «ออก» จนเคยชินใช่ไหม คีย์ลัด «ไม่ให้หลับ» และเพื่อนตัวน้อยของคุณก็ยังทำงานต่อไป

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/keep-awake-dark.png"><img src="../media/keep-awake-light.png" width="340" alt=""></picture>

เมื่อคุณเลือก «ออก» กด ⌘Q หรือออกจาก pikapik ผ่าน Dock แอปจะปิดหน้าต่างและซ่อนไอคอนในแถบเมนู แต่ยังทำงานเงียบ ๆ อยู่เบื้องหลัง: คีย์ลัด «ไม่ให้หลับ» และเพื่อนตัวน้อยยังเปิดอยู่ หากต้องการให้ไอคอนกลับมา แค่เปิด pikapik อีกครั้ง

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/pet-dark.png"><img src="../media/pet-light.png" width="340" alt=""></picture>

อยากออกจริง ๆ ใช่ไหม กด Option (⌥) ค้างไว้แล้วเลือก «ออก» หรือกด ⌥⌘Q ครั้งแรกที่ pikapik ไปทำงานเบื้องหลัง แอปจะอธิบายว่าเกิดอะไรขึ้น และให้คุณออกทั้งหมดได้ทันที

ชอบแบบเดิมมากกว่าใช่ไหม ปิด «ทำงานต่อเบื้องหลังหลังจากออก» ใน การตั้งค่า › ทั่วไป การอัปเดต การเปลี่ยนภาษา การออกจากระบบ การเริ่มการทำงานใหม่ และการปิดเครื่อง จะทำให้ pikapik ออกทั้งหมดเสมอ จึงไม่ต้องรอแอปเลย

**ลองใช้:** กด ⌘Q แล้วเปิด pikapik อีกครั้งเพื่อให้ไอคอนกลับมา

และเพื่อนตัวน้อยจะไม่หายไปอีกแล้ว ทุกสองวินาทีจะคอยเช็กว่ายังอยู่บนจอ ถ้ามีอะไรผิดพลาดหลังพักเครื่อง ล็อก Mac สลับเดสก์ท็อป หรือเต็มจอ ก็จะกลับมาเองทันที

## <a id="v1.23.0"></a>โหมดเกม: เล่นได้ไม่มีสะดุด

<sub>1.23.0 · 7 ตุลาคม 2569</sub>

เพิ่มเกมของคุณ แล้ว Mac จะไม่ดึงคุณออกจากเกมอีก

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/game-mode-dark.png"><img src="../media/game-mode-light.png" width="340" alt=""></picture>

ระหว่างที่คุณเล่น Spotlight, Siri, ⌘Tab, Mission Control และการปัดระหว่างเดสก์ท็อปจะไม่เปิดทับเกม ⌘Q และ ⌘W จะไม่ปิดเกมโดยไม่ตั้งใจ ตัวชี้จะอยู่บนหน้าจอของเกม และหน้าจอจะเปิดค้างไว้

หากต้องการออกจากเกม ให้กด ⇧⌘Q หากต้องการปิดหน้าต่างเกม ให้กด ⇧⌘W ส่วน ⌥⌘Esc ใช้ได้เสมอ pika-tools จะแนะนำเกมที่พบใน Mac ของคุณ โหมดเกมจะปิดอยู่จนกว่าคุณจะเปิด

“ไม่ให้หลับ” ให้คุณเลือกได้แล้วว่าหน้าจอจะทำอะไร: เปิดค้างไว้โดยไม่มีภาพพักหน้าจอหรือหน้าจอล็อก หรือดับตามปกติขณะที่ Mac ยังทำงานต่อ ปุ่มใหม่ “ปิดหน้าจอตอนนี้” จะทำให้หน้าจอดับทันที ขยับเมาส์หรือกดปุ่มใดก็ได้เพื่อให้กลับมา

**ลองใช้:** การตั้งค่า › เกม แล้วกด “เพิ่มเกม…”

**สิ่งที่แก้ไข**

- บน Mac ที่ไม่มีฝาพับ “ไม่ให้หลับ” จะไม่แสดงตัวเลือกสำหรับตอนปิดฝาอีกต่อไป
