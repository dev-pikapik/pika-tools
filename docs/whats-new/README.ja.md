## <a id="v1.52.2"></a>ペットが気持ちを見せ、プレーヤーで画像も開けるように

<sub>1.52.2 · 2026年10月17日</sub>

ペットが気持ちを表すようになり、プレーヤーで画像も開けるようになりました。Dock にしまったウインドウは、ゲーム中に戻ってこなくなりました。

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/pet-dark.png"><img src="../media/pet-light.png" width="340" alt=""></picture>

表情が変わり、頭の上にハートやキラキラ、小さな雲などの印が出て、いまの気持ちがわかります。衣装には口ひげや帽子、髪型など 15 個の新しいアイテムが増えました。

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/player-dark.png"><img src="../media/player-light.png" width="340" alt=""></picture>

Webサイト版では、画像も同じプレーヤーで「プレビュー」のように開けます。JPEG、PNG、HEIC、カメラの RAW、PSD などに対応しています。

- プレーヤー（Webサイト版）：音声トラックや字幕を選べて、チャプター間を移動でき、A キーで一部分をくり返し再生できます。
- プレーヤー（Webサイト版）：ピクチャ・イン・ピクチャ、テレビへの AirPlay、Mac の出力を変えずに別のスピーカーから音を出す機能。

**試してみる：** 設定 › ペット · 設定 › プレーヤー

**修正**

- ゲーム（Webサイト版）：ゲームを開いたり閉じたりしても、Dock にしまったウインドウが戻ってこなくなりました。
- ⇧⌘Q や自分で決めた終了ショートカットで、毎回アプリが終了するようになりました。
- デスクトップのアイコンを隠すのをやめると、デスクトップのファイルが必ず戻るようになりました。
- Chrome、Slack、VS Code（Webサイト版）：ほかのアプリがオンにした機能を pikapik がオフにしなくなり、pikapik を終了すると Chrome は元どおりに戻ります。
- 設定：ビデオ、ミュージック、画像はそれぞれスイッチ 1 つになり、左のリストにはいつも開いているページが表示されます。

## <a id="v1.52.1"></a>プレーヤーが音楽を再生し、クラッシュ後も設定が元に戻ります

<sub>1.52.1 · 2026年10月16日</sub>

プレーヤーで曲が聴けるようになり、ガラス風のパネルになりました。クラッシュしても設定が元に戻ります。

- プレーヤー（Webサイト版）：曲は同じウインドウで、ジャケット・タイトル・アーティスト付きで再生され、フォルダは曲を順に再生します。
- プレーヤー（Webサイト版）：各フォーマットがボタンになり、pikapik Player に渡したり元に戻したりできます。「すべてを pikapik で開く」で一度にすべて行えます。
- プレーヤー（Webサイト版）：見ている間は隠れるすりガラスのコントロールパネルと、タイムバーに合わせると出る動画の小さな画像。

**試してみる：** 設定 › プレーヤー

**修正**

- 「Dock を自動的に隠す」などの設定が、pikapik が突然止まっても元に戻ります。
- Chrome、Slack、VS Code（Webサイト版）：クラッシュ後も pikapik のモードのまま残らなくなり、固まったウインドウが pikapik の起動や終了を遅くしなくなりました。
- サイドボタン：設定で 4 と 5 の代わりに戻る・進む矢印を表示し、「進む」が Mail や Outlook でメールを転送しなくなりました。
- 「このコピーをメインにする」は1回の操作で1回だけ働くようになり、一部のスイッチの下の短い説明がより分かりやすくなりました。
- Mac App Store版：「ペット」ページが、アップデートのお知らせを約束しなくなりました。App Store が自動でお届けするためです。

## <a id="v1.52.0"></a>言語違いの修正もマウスのサイドボタンも、ほとんどのアプリで使えるように

<sub>1.52.0 · 2026年10月15日</sub>

違う言語で打った単語の修正が Chrome、Slack、VS Code でも働くようになり、マウスのサイドボタンはほぼどこでも「戻る」「進む」になりました。

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/layout-fix-dark.png"><img src="../media/layout-fix-light.png" width="340" alt=""></picture>

Webサイト版で、違う言語で打ってしまった単語の修正が、Chrome、Slack、VS Code、Discord などのアプリでも使えるようになりました。「ghbdtn」がそこでも「привет」になります。機能をオフにするか pikapik を終了すると、これらのアプリは元の状態に戻ります。

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/side-buttons-dark.png"><img src="../media/side-buttons-light.png" width="340" alt=""></picture>

マウスのサイドボタンが、ほとんどのアプリで「戻る」「進む」になり、pikapik 自身の設定でもまた使えます。pikapik がそのアプリ自身の「戻る」または「進む」ボタンを代わりに押します。Mac App Store 版では、pikapik と Apple のアプリで使えます。

pikapik を2つ開いたとき（たとえば Webサイト版と App Store 版）、Mac に変更を加えるのは最後に開いたほうだけなので、設定にはいつも実際の状態が表示されます。終了すると、変更したものはすべて元に戻ります。

**そのほかの新機能**

- 「トラックパッドで中央クリック」：3本指でタップします（Webサイト版）。
- 「アプリを終了」と「ウインドウを閉じる」は、キーの動作を絵で示します。
- ⇧⌘. は「隠しファイルを表示」の行にそのまま入りました。
- 設定のサイドバーにグループ名が付きました。
- プレーヤー（Webサイト版）：QuickTime Player と同じキー、ホイールでの音量調整、再生速度、続きから再生。

**試してみる：** 設定 › キーボード、設定 › マウス

**修正**

- アップデート直後、プレーヤーを一度も開いていなくても「このアプリケーションで開く」に pikapik Player が表示されます。
- アプリの音量：スライダーを 100% に戻したとき、音の最後に小さなクリック音が入らなくなりました。
- ゲーム（Webサイト版）：マウスを素早く動かしても別のディスプレイにはみ出さず、ポインタが戻されることもありません。

## <a id="v1.51.0"></a>QuickTime で開けないビデオが再生できるようになりました

<sub>1.51.0 · 2026年10月15日</sub>

Webサイト版で、QuickTime で開けない MKV、WebM、AVI、WMV、FLV などのビデオを pikapik Player で再生できるようになりました。

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/player-dark.png"><img src="../media/player-light.png" width="340" alt=""></picture>

ビデオを右クリックして このアプリケーションで開く › pikapik Player を選ぶか、設定 › プレーヤー で ビデオを開く… をクリックします。ビデオは専用のウインドウで再生されます。スペースバーで再生と一時停止、← と → で 5 秒移動、↑ と ↓ で音量を変更、F でフルスクリーンになります。

プレーヤーは小さな別のアプリです。開いたビデオにしかアクセスできず、インターネットにも接続できず、アクセス許可も求めません。ビデオを開くデフォルトのアプリは変わりません。字幕にはまだ対応していません。

**試してみる：** 設定 › プレーヤー

## <a id="v1.50.2"></a>システム設定へ行かなくても、pikapikがやってくれます

<sub>1.50.2 · 2026年10月15日</sub>

Webサイト版では、バックグラウンドタスクをオフにする、キーボードレイアウトを追加する、ホットコーナーを変える、主ディスプレイを選ぶ、といった操作が、pikapikの中でそのままできるようになりました。

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/background-dark.png"><img src="../media/background-light.png" width="340" alt=""></picture>

設定 › バックグラウンドタスク でタスクをオフにすると、その行がすぐに変わります。パスワードは要らず、選んだ内容は再起動後も残ります。「オンに戻す」でタスクが戻ります。Mac全体向けのタスクや、アプリが自分で追加したヘルパーは、これまでどおりシステム設定が開き、行の下の一文が理由を伝えます。

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/layout-fix-dark.png"><img src="../media/layout-fix-light.png" width="340" alt=""></picture>

違うレイアウトで打った文字の修正は、キーボードレイアウトが2つ以上あるときに使えます。1つしかない場合は、設定 › キーボード のメモに、お使いの言語向けのレイアウトが表示されるようになりました。「レイアウトを追加」から選ぶとすぐ使え、パスワードは要りません。合うものがなければ「キーボード設定…」もそのままあります。

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/dock-display-dark.png"><img src="../media/dock-display-light.png" width="340" alt=""></picture>

設定 › ゲーム では、ホットコーナーの行の「変更…」メニューで、そのコーナーの動作を別のものに変えられます。「Dockを1台のディスプレイに固定」では、「主ディスプレイ」メニューで選んだディスプレイが主ディスプレイになり、Dockもそこへ移ります。pikapikは元の状態を覚えていて、「元に戻す」かスイッチをオフにすると、そのとおりに戻ります。

**試してみる：** 設定 › バックグラウンドタスク

**修正**

- Dockのクリックでしまう・隠す：クリックでウインドウをしまう設定のときにオンにすると、再起動のあとでアプリを隠す設定に勝手に変わることがなくなりました。
- pikapikを開くと、もう1台のMacで変えた設定があるか確認するようになり、変更を逃したMacもすぐに追いつきます。
- 「スリープさせない」は、オフにするまでオンのままだと表示するようになり、「ゲームモード」は追加済みのゲームをもう勧めません。

## <a id="v1.50.0"></a>Mac App Store 版の pikapik が、さらに充実

<sub>1.50.0 · 2026年10月15日</sub>

アーカイブを開く、デスクトップをすっきりさせる、Home と End を使う。これらが Mac App Store 版でも使えるようになりました。

**Mac App Store 版の新機能**

- **Finder でアーカイブを開いたり作ったりできます。** アーカイブを右クリックして「展開」を選びます。作るときは、ファイルを右クリックして「アーカイブを作成…」を選びます。アーカイブでスペースキーを押すと、中身を確認できます。この版でパスワードを付けられるのは ZIP だけです。
- **デスクトップをすっきりさせられます。** 「デスクトップのアイコンを隠す」をオンにすると、pikapik が壁紙でアイコンを覆います。クリックはこれまでどおりデスクトップに届き、許可は要りません。
- **Home と End がまた使えます。** 行頭と行末へ移動します。ブラウザ、Finder、ミュージック、TV 以外のすべての場所で使えます。
- **ショートカットで、違う配列で打った文字を直せます。** テキストを選んで ⌃⇧スペースを押します。「選択したテキストを修正」は 設定 › キーボード でオンにでき、キーも変えられます。
- **ワンクリックでディスプレイをオフにできます。** 「今すぐディスプレイをオフ」を使うと、Mac が動いたまま、ディスプレイがすぐに暗くなります。マウスを動かすと戻ります。
- **ゲーム中に邪魔されません。** 「ゲームモード」では、ゲームが前面にある間、Spotlight など Mac のショートカットが一時停止します。ポインタは画面の隅に近づかないので、ホットコーナーも動きません。
- **バッテリーの数値が戻りました。** 「バッテリー」に macOS 27 でも「最大容量」が表示され、「温度」にはバッテリーの温度が表示されます。
- **許可を求められるアプリがわかります。** 設定 › 許可 の「他のアプリのアクセス許可」に、アプリがアイコン付きで並びます。
- **どこをクリックすればいいかわかります。** macOS が pikapik による設定の変更を許可しないときは、システム設定のどこをクリックするかを短いアニメーションで示します。

**どちらの版でも**

- **アプリが起動する前に音量を決められます。** 音量を設定したアプリは、閉じていても設定 › サウンドにスライダーごと残り、次に音を出したとき、再起動のあとでも、その音量に戻ります。「アプリを追加…」をクリックするか Finder からアプリをドラッグすれば、先に設定でき、✕ を押すとそのアプリを忘れて音量を最大に戻します。
- **アップデートで増えたものがひと目で。** アップデート後は、新しい内容がある設定のタブに小さな青い点が付き、そのセクションに「新着」のタグが付きます。見ると消え、21日たつと自然に消えます。
- **落ち着いた初回起動。** Web サイト版は、初めて開いたときに権限を求めなくなりました。権限が必要なツールをオンにしたときだけ尋ねます。
- **動画の小さいコピーが作れます。** 「小さいコピーを作成」で、動画がおよそ半分のサイズになります。以前は、ほとんどの動画で「すでに十分小さいファイルです」と表示されていました。
- **2 つの版を一緒に使えます。** App Store 版と Web サイト版を同時に使っても、お互いの動作を打ち消さなくなりました。ゲーム中の ⇧⌘Q と ⇧⌘W も、また使えます。
- **スリープ明けもゲームモードが続きます。** Mac がスリープから復帰すると、「ゲームモード」が自動でオンに戻ります。
- **「ポート」が正しく教えてくれます。** macOS 27 で、macOS や別のユーザが使っているポートを「空き」と表示しなくなりました。
- **問題の報告が楽になりました。** 設定 › 情報 の「問題を報告」を押すと、お使いのバージョンがすでに選ばれたフォームが開きます。
- **アーカイブがもっとなめらかに。** アーカイブの展開中は進行バーが動き、パスワードが違うときはすぐにお知らせし、展開や作成の途中で Mac がスリープすることもなくなりました。
- **安定したメニューバーパネル。** 「スリープさせない」の下のディスプレイのオプションなど、パネルの行を開いてもスクロールバーがちらつかなくなりました。「スリープさせない」の横の矢印には「ディスプレイの設定」と表示されます。
- **ポートが自分で説明します。** タイトルの下の一行がポートとは何かを伝え、小さなアニメーションが「1つのドアを通れるプログラムは1つだけ」と見せてくれます。ご自身のプログラムと、そっとしておくべきプログラムには、わかりやすい名前が付きました。
- **設定の言葉がわかりやすく。** 各タブは、そこで何ができるかを伝える一行で始まり、サイドバーはグループの間にすき間ができ、「スリープさせない」「許可」「バッテリー」は今の状況をそのまま伝えます。「許可が必要です」ボタンは、オンにしたツールに許可が足りないときだけ表示されます。

**Mac App Store 版の修正**

- Finder で ⌘X のあとに ⌘V を押すと、Web サイト版と同じようにファイルが移動します。以前は、コピーされるだけでした。
- 「Finderで新規ファイル」「Finderで小さいコピー」「Finderで変換」が、それぞれ自分の状態を表示します。以前は、1 つをオンにすると 3 つともオンに見えました。
- 空っぽの「ポート」ページはなくなりました。macOS はこの版に、どのプログラムがポートを使っているかを教えないため、設定 › ポート には表示するものがありませんでした。

## <a id="v1.49.0"></a>どのモニタでも明るさを調節できます

<sub>1.49.0 · 2026年10月13日</sub>

macOS が調節できないモニタも、pikapik から暗くしたり明るくしたりできます。

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/brightness-dark.png"><img src="../media/brightness-light.png" width="340" alt=""></picture>

macOS は内蔵ディスプレイと Apple 製ディスプレイの明るさを調節しますが、ほかの多くのモニタは本体のボタンにしか反応しません。これからは、そうしたモニタごとに 設定 › 明るさ のスライダーが付きます。メニューバーのパネルに「明るさ」の行を追加することもできます。

pikapik が変えるのはモニタ本体の明るさで、モニタのボタンと同じです。反応しないモニタでは「代わりに画面を暗くする」をオンにしてください。画面は暗くなりますが、真っ黒にはなりません。pikapik はモニタごとの明るさを覚えていて、スリープ後にもう一度設定します。

「明るさキー」をオンにすると、キーボードの明るさキーでポインタがあるモニタの明るさを変えられ、画面に小さなインジケータが表示されます。⌥⇧ を押しながら操作すると、より細かく調節できます。キーを使うには「アクセシビリティ」の許可が必要で、「許可」ページで許可できます。

**試してみる：** 設定 › 明るさ

**修正**

- VoiceOver で、設定のスイッチをオン・オフできるようになりました。これまでは各スイッチの名前を 2 回読み上げ、押しても何も起きませんでした。

## <a id="v1.48.0"></a>マウスをどんなに速く動かしても、Dock は今のディスプレイにとどまります

<sub>1.48.0 · 2026年10月13日</sub>

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/dock-display-dark.png"><img src="../media/dock-display-light.png" width="340" alt=""></picture>

## <a id="v1.38.0"></a>Finderでアーカイブを開く、作る

<sub>1.38.0 · 2026年10月12日</sub>

新しい「Finderでアーカイブ」は、macOS では開けない RAR などのアーカイブを開き、右クリックのメニューから ZIP や 7Z を作れます。

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/archive-dark.png"><img src="../media/archive-light.png" width="340" alt=""></picture>

設定 › Finder を開き、「Finderでアーカイブ」をオンにします。アーカイブを右クリックして「展開」を選ぶと、中のファイルがアーカイブのすぐ隣に現れます。ほかのファイルやフォルダを右クリックして「アーカイブを作成…」を選ぶと、ZIP、7Z、TAR.GZ、TAR.XZ を作れます。ZIP と 7Z にはパスワードを付けられ、どのアーカイブも、たとえばメールに添付できる 15 MB ずつの複数の部分に分けられます。この方法で作った ZIP には余分な隠しファイルが入らず、どの言語のファイル名も読める形のままです。

パスワードが必要なときはウインドウで尋ね、「停止」を押すとどの作業も中止でき、壊れたアーカイブからは読める部分を取り出します。展開すると途方もない大きさに膨らむアーカイブは展開前に確認し、自分のフォルダの外に書き込もうとするアーカイブは止めます。Mac App Store 版にはありません。アーカイブを選んでスペースキーを押すと、中身をプレビューできます。
