## <a id="v1.30.0"></a>「終了」してもpikapikは止まらなくなりました

<sub>1.30.0 · 2026年10月9日</sub>

うっかり「終了」を選んでも、ショートカット、「スリープさせない」、ペットはそのまま動き続けます。

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/keep-awake-dark.png"><img src="../media/keep-awake-light.png" width="340" alt=""></picture>

「終了」を選ぶ、⌘Qを押す、またはDockからpikapikを終了すると、ウインドウを閉じてメニューバーのアイコンを隠しますが、バックグラウンドで静かに動き続けます。ショートカット、「スリープさせない」、ペットはそのままです。アイコンを戻すには、pikapikをもう一度開くだけです。

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/pet-dark.png"><img src="../media/pet-light.png" width="340" alt=""></picture>

本当に終了したいときは、Option（⌥）キーを押しながら「終了」を選ぶか、⌥⌘Qを押します。pikapikが初めてバックグラウンドに移るときは、何が起きたかを説明し、その場で完全に終了することもできます。

以前の動作がよければ、「設定」›「一般」で「終了後もバックグラウンドで動作」をオフにしてください。アップデート、言語の変更、ログアウト、再起動、システム終了のときは、いつもpikapikが完全に終了するので、待たされることはありません。

**試してみる：** ⌘Qを押してから、もう一度pikapikを開いてアイコンを戻してみましょう。

## <a id="v1.28.0"></a>アプリはクリックやドラッグで追加

<sub>1.28.0 · 2026年10月9日</sub>

設定のアプリ一覧に、Dock にあるアプリと今開いているアプリが並ぶようになりました。Finder からドラッグして追加することもできます。

<picture><source media="(prefers-color-scheme: dark)" srcset="../media/whats-new/1.28.0/app-shelf-dark.png"><img src="../media/whats-new/1.28.0/app-shelf-light.png" width="340" alt=""></picture>

緑のボタンや Home と End のように、機能によっては働かないアプリを選べます。これまで「アプリを追加…」を押すと、すべてが入った長いフォルダが開くだけでした。これからは、Dock のアプリと今開いているアプリが棚に並びます。クリックすれば追加、もう一度クリックすれば取り消し。それ以外のアプリは「その他…」から選べます。

Finder からアプリを一覧の上へそのままドラッグすることもできます。どこに入るのか、一覧が光って教えてくれます。ゲームも同じ棚で、同じように追加できます。

うまくいかないときのために、GitHub の不具合報告フォームでは pikapik と macOS のバージョンを一覧から選べるようになりました。お知らせいただく手間が少なくなります。

**試してみる：** 設定 › ウインドウ で「アプリを追加…」

**修正**

- 両方の Mac でクラシックなスクロール方向を使っているとき、AnyDesk などのリモートデスクトップ越しのスクロールが二重に逆転しなくなりました。pikapik は本物のマウスやトラックパッドのスクロールだけを反転します。Mos のように自分でなめらかなスクロールを作るアプリでは、そのアプリで方向を設定してください。
- ペットはジャンプ中も歩いているときと同じように Dock の後ろにいます。フルスクリーンのアプリやゲームを終えると、自分で戻ってきます。
- 設定の小さなイラストを囲む細い枠が、Retina ではない一般的なディスプレイでも消えなくなりました。
